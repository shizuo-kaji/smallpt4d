鏡だけに映る光源

基準視点で橙色の光源を消すと、鏡の中の像が消えます。カメラから直接見えない光源を、鏡からの反射光線が捉えます。

操作ガイド

鏡に映る4次元目

各眼から出た一次光線は、視点と2次元の撮像面が張る3次元空間を進みます。超球面で反射・屈折・散乱した光線は、この空間の外にある光源にも届きます。

「鏡面」の基準視点で、橙色の光源を点灯して「二次光線の追跡回数」を 0 にします。次に 1 に上げると、1回の反射で光源に届き、鏡に橙色の像が現れます。
